# FVM_2D

A 2D cell-centred finite-volume solver for the Euler and shallow-water equations on unstructured
meshes (triangles and quadrilaterals read from gmsh). It uses a second-order MUSCL scheme with
Roe or HLLC fluxes, Barth-Jespersen or Venkatakrishnan limiters, least-squares or Green-Gauss
gradients, and explicit Euler or RK2 time stepping. The hot loops are numba-compiled, and the
solver runs serially, with numba threads, or distributed with MPI.

## Install

```
pip install -r requirements.txt          # numpy, scipy, gmsh, matplotlib, numba
pip install -r requirements-mpi.txt      # optional: mpi4py for distributed runs
```

## Run an example

Each folder in `examples/` is one physical problem. The algorithm is chosen on the command line:

```
python examples/euler_riemann/main.py
python examples/euler_riemann/main.py --flux hllc --limiter venkatakrishnan --integrator euler
python examples/shallow_water_riemann/main.py --mesh data/river_triangular.msh --t-end 10
python examples/euler_riemann/main.py --mesh unit_square:40 --no-plot     # no gmsh mesh needed
mpiexec -n 4 python examples/euler_riemann/main.py                        # distributed
```

`--help` lists every option (flux, limiter, gradient, integrator, CFL, fixed `--dt`, mesh,
output folder, ...). Meshes in `data/*.msh` are generated by `utility/mesh_generation/`.

## Layout

| Folder | Contents |
| --- | --- |
| `src/` | Solver library (mesh, reconstruction, fluxes, time stepping, partitioning, driver). |
| `examples/` | One `main.py` per problem. |
| `tests/unit/`, `tests/integration/` | pytest suites: `python -m pytest` (or one folder). |
| `utility/` | Standalone tools: `mesh_generation/`, `benchmarks/`, `checks/`, `figures/`. |
| `data/`, `doc/` | Meshes and sample arrays; notes and figures. |

See [ARCHITECTURE.md](ARCHITECTURE.md) for the design and [PARALLEL_GUIDE.md](PARALLEL_GUIDE.md)
for the MPI implementation.
